📘 คู่มือการใช้งานเว็บไซต์ร้านค้าออนไลน์ (หน้าเดียวจบ)
✅ 1. เปิดใช้งานครั้งแรก (สำคัญที่สุด)

แตกไฟล์ ZIP ที่ดาวน์โหลด

จะได้ไฟล์หลัก:

index.html

style.css

script.js

โฟลเดอร์ products/

โฟลเดอร์ qr/

ดับเบิลคลิกที่ index.html
✅ ร้านค้าจะเปิดขึ้นทันทีผ่านเบราว์เซอร์

❗ ไม่ต้องติดตั้ง Host, ไม่ต้องลง XAMPP, ไม่ต้องใช้ Internet ก็เปิดได้

✅ 2. วิธีเปลี่ยน “ชื่อสินค้า”

เปิดไฟล์:
👉 script.js

มองหาบรรทัดลักษณะนี้:

name: "เต็นท์เดี่ยว"


เปลี่ยนข้อความในเครื่องหมายคำพูดได้ทันที เช่น:

name: "เต็นท์แคมป์ปิ้ง 2 คน รุ่น Pro"


✅ บันทึกไฟล์ (Ctrl + S)
✅ รีเฟรชหน้าเว็บ → ชื่อใหม่จะแสดงทันที

✅ 3. วิธีเปลี่ยน “ราคา”

ในไฟล์ script.js ตำแหน่งเดียวกับชื่อสินค้า:

price: 1200


เปลี่ยนเป็น:

price: 1590


✅ ระบบตะกร้า และราคารวม จะเปลี่ยนตามอัตโนมัติ

✅ 4. วิธีเปลี่ยน “รูปสินค้า”

นำรูปใหม่ไปใส่ในโฟลเดอร์:

products/


เปลี่ยนชื่อใน script.js:

img: "products/tent1.jpg"


เป็น:

img: "products/tent-new.jpg"


✅ ชื่อไฟล์ต้องตรง 100%
✅ ตัวพิมพ์เล็ก-ใหญ่มีผล

✅ 5. วิธีเพิ่ม “สินค้าใหม่”

ในไฟล์ script.js ให้คัดลอกบล็อกสินค้าหนึ่งอัน:

{
  id: 1,
  name: "เต็นท์เดี่ยว",
  price: 1200,
  img: "products/tent1.jpg",
  category: "single"
},


แล้ววางต่อท้าย:

{
  id: 6,
  name: "เก้าอี้พับ",
  price: 690,
  img: "products/chair1.jpg",
  category: "tools"
},


✅ เพิ่มสินค้าได้ไม่จำกัด

✅ 6. วิธีเปลี่ยน “หมวดหมู่สินค้า”

หมวดหมู่จะอยู่ใน script.js:

category: "single"


คุณสามารถตั้งเป็นอะไรก็ได้ เช่น:

"tent"

"lamp"

"set"

"gift"

❗ หมวดหมู่ในสินค้า ต้อง ตรงกับหมวดที่อยู่ใน <select> ของหน้าเว็บ

✅ 7. วิธีเพิ่ม / เปลี่ยน หมวดหมู่ในหน้าเว็บ

เปิดไฟล์:
👉 index.html

มองหาส่วนนี้:

<select id="categorySelect">
  <option value="all">สินค้าทั้งหมด</option>
  <option value="single">สินค้าเดี่ยว</option>
  <option value="set">สินค้าแบบชุด</option>
</select>


เพิ่มได้แบบนี้:

<option value="lamp">ไฟแคมป์ปิ้ง</option>


✅ value ต้องตรงกับ category ใน script.js

✅ 8. วิธีเปลี่ยน QR Code การชำระเงิน

เอารูป QR ใหม่ไปใส่ในโฟลเดอร์:

qr/


ตั้งชื่อไฟล์เป็น:

qr-pay.png


✅ หน้า payment.html จะเปลี่ยนให้ทันที

✅ 9. วิธีเปลี่ยนลิงก์ WhatsApp / Facebook

เปิด:
👉 index.html

เปลี่ยนลิงก์ตรงนี้:

<a href="https://wa.me/66xxxxxxxxx">WhatsApp</a>
<a href="https://facebook.com/yourpage">Facebook</a>


ใส่ลิงก์จริงของคุณแทนได้เลย
